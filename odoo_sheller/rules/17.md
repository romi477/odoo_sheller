# Odoo 17

Python 3.10 or newer.

## Python

- Cache: `env.flush_all()`, `records.flush_model()`,
  `records.flush_recordset()`, `env.invalidate_all()`,
  `records.invalidate_model()`, `records.invalidate_recordset()`. The 15
  names `flush()` and `invalidate_cache()` are gone. In the shell {{commit}}
  and {{rollback}} already do this; you need it only inside a script that
  writes and then reads back with SQL.
- The label is `display_name`, computed by `_compute_display_name`.
  Override that to change how a record is named, and set
  `_rec_names_search` to search on more than `_rec_name`. `name_get` still
  exists and is deprecated; it is gone in 18, so do not add a new one.
- `_read_group(domain, groupby, aggregates)` is the grouping call for code:
  it returns a list of tuples, groupby values then aggregates, with
  aggregates spelled `'amount:sum'` or `'__count'`. `read_group(domain,
  fields, groupby)` still exists for the web client and returns dicts.
- Access checks are `check_access_rights(operation)` and
  `check_access_rule(operation)`. `check_access` and `has_access` are 18.
- SQL constraints are `_sql_constraints = [(name, sql, message)]`.
- Field aggregation is `group_operator='sum'`. `aggregator` is 18.
- `SQL` exists (`from odoo.tools import SQL`) and composes a query with its
  parameters: `cr.execute(SQL("SELECT id FROM %s WHERE state = %s",
  SQL.identifier(table), state))`. A string with a params tuple still runs.
  Never build the query with `%` or an f-string on a plain string.
- `res.users.groups_id` and `res.groups.users` are the membership fields;
  a group's category is `category_id`.
- `ir.config_parameter`: `get_param(key, default)` and `set_param`.

## XML

- `attrs` and `states` are gone. A view that still has them fails to load:
  `Since 17.0, the "attrs" and "states" attributes are no longer used.`
  Modifiers are Python expressions on the attribute itself:

  ```xml
  <field name="name" invisible="state == 'cancel'" readonly="state != 'draft'"/>
  <field name="partner_id" column_invisible="True"/>
  <button name="action_done" invisible="state not in ('draft', 'sent')"/>
  ```

  The expression sees fields in the same view, plus `context`, `uid`,
  `parent`, `id`. A field an expression needs must be in the view, with
  `invisible="1"` if nobody should see it. In a list, `column_invisible`
  hides the column and `invisible` hides the cell.
- The list view root is still `<tree>`, the view type `tree`, `view_mode`
  `tree,form`, and an xpath into a list says `//tree`. `<list>` is 18 and
  is not a valid root here.
- A kanban card is still `<t t-name="kanban-box">`.
- QWeb output is `t-out`. `t-esc` still works; `t-raw` is deprecated and
  warns.
- Access is `security/ir.model.access.csv`, record rules are `ir.rule`.
- A JSON controller is `@http.route(..., type='json')`.
