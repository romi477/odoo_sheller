# Odoo 19

Python 3.10 or newer (`MIN_PY_VERSION` in this release).

## Python

- Cache: `env.flush_all()`, `records.flush_model()`,
  `records.flush_recordset()`, `env.invalidate_all()`,
  `records.invalidate_model()`, `records.invalidate_recordset()`. In the
  shell os_commit and os_rollback already do this; you need it only inside a
  script that writes and then reads back with SQL.
- `_sql_constraints` is no longer applied. A model that still defines it
  loads and logs `Model attribute '_sql_constraints' is no longer
  supported, please define models.Constraint on the model.` — and the
  constraint silently does not exist. Constraints and indexes are model
  attributes whose name starts with `_`:

  ```python
  _name_uniq = models.Constraint("UNIQUE(name)", "Name must be unique.")
  _name_idx = models.Index("(name)")
  _code_uniq = models.UniqueIndex("(company_id, code)")
  ```

- Domains can be built with `Domain` (`from odoo.fields import Domain`):
  `Domain('state', '=', 'draft') & Domain('company_id', 'in', ids)`. A list
  domain still works everywhere.
- `_read_group(domain, groupby, aggregates)` is the grouping call for code
  and returns tuples. `read_group` is deprecated; the web client calls
  `formatted_read_group`.
- `record._cr`, `record._context` and `record._uid` are deprecated. Write
  `record.env.cr`, `record.env.context`, `record.env.uid`.
- `@api.private` marks a public-looking method that must not be callable
  over RPC.
- Access is `check_access`, `has_access`, `_filtered_access`, as in 18.
  `check_access_rights` and `check_access_rule` still delegate and warn.
- Field aggregation is `aggregator='sum'`.
- The label is `display_name` via `_compute_display_name`; `name_get` is
  gone.
- Group membership is renamed. On `res.users`, `groups_id` is `group_ids`
  (assigned) and `all_group_ids` (with implied groups). On `res.groups`,
  `users` is `user_ids` and `all_user_ids`. A group's `category_id` is
  `privilege_id`, pointing at `res.groups.privilege`. `groups_id` in a
  `create` or a domain fails.
- `SQL` (`from odoo.tools import SQL`) is the way to compose a raw query.
  Never build the query with `%` or an f-string on a plain string.
- `ir.config_parameter`: `get_param(key, default)` and `set_param`.

## XML

- The list view root is `<list>`, type `list`, `view_mode` `list,form`,
  xpath `//list`. `<tree>` is not a view type.
- Modifiers are Python expressions on the attribute:
  `invisible="state == 'cancel'"`, `column_invisible="True"`.
- A kanban card must be `<t t-name="card">`. There is no fallback to
  `kanban-box` any more; a view without `card` fails with `Missing 'card'
  template.`
- A group in data XML sets `privilege_id`, not `category_id`; a user sets
  `group_ids`.
- QWeb output is `t-out`. `t-raw` is deprecated and warns.
- Access is `security/ir.model.access.csv`, record rules are `ir.rule`.
- A JSON controller is `@http.route(..., type='jsonrpc')`. `type='json'`
  still runs and warns `Since 19.0, @route(type='json') is a deprecated
  alias to @route(type='jsonrpc')`.
