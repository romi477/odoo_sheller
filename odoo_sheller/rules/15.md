# Odoo 15

Python 3.7 or newer (`python_requires` in this release). Do not write 3.10
syntax: no `match`, no `X | Y` in a runtime annotation.

## Python

- The cache API is the old one. `env.flush_all()` and
  `env.invalidate_all()` do not exist here. Flush everything with
  `env['base'].flush()`, one model with `records.flush(['field'])`, and drop
  the cache with `records.invalidate_cache()` or `env.clear()`. In the shell
  os_commit and os_rollback already do the right one; you need these only
  inside a script that writes and then reads back with SQL.
- The label is `name_get()`, returning `[(id, name)]`. `display_name` is
  computed from it. To change how a record is named, override `name_get`;
  for search, `_name_search`.
- Grouping is `read_group(domain, fields, groupby)`, returning a list of
  dicts with `<groupby>_count`. There is no `_read_group` with aggregates.
- Access checks are `check_access_rights(operation)` and
  `check_access_rule(operation)`. `check_access` and `has_access` are 18.
- SQL constraints are `_sql_constraints = [(name, sql, message)]`.
- Field aggregation is `group_operator='sum'`. `aggregator` is 18.
- Raw SQL is a string with parameters: `cr.execute(query, params)`. There is
  no `SQL` object yet. Never build the query with `%` or an f-string.
- `res.users.groups_id` and `res.groups.users` are the membership fields;
  a group's category is `category_id`.
- `ir.config_parameter`: `get_param(key, default)` and `set_param`.

## XML

- The list view root is `<tree>`, the view type is `tree`, `view_mode` is
  `tree,form`, and an xpath into a list says `//tree`. `<list>` is not a
  view here.
- Dynamic modifiers are `attrs` and `states`, with domains:

  ```xml
  <field name="name" attrs="{'invisible': [('state', '=', 'cancel')], 'readonly': [('state', '!=', 'draft')]}"/>
  <button name="action_done" states="draft,sent"/>
  ```

  A bare `invisible="1"` is static. A Python expression such as
  `invisible="state == 'cancel'"` is 17 and does not work here.
- A column hidden in a list is `invisible="1"` on the field, or a domain in
  `attrs` for `column_invisible`. Do not write `column_invisible=` yourself.
- A kanban card is `<t t-name="kanban-box">`.
- QWeb output is `t-out` (escaped) or `t-esc`. `t-raw` is deprecated and
  warns; wrap trusted HTML in `markupsafe.Markup` and use `t-out`.
- Access is `security/ir.model.access.csv`, record rules are `ir.rule`.
- A JSON controller is `@http.route(..., type='json')`.
