# Odoo 20

Python 3.12 or newer (`MIN_PY_VERSION` in this release), PostgreSQL 16 or
newer. Much moved in this release; when a name from 19 fails, read the 20
source with {{source}} before guessing a replacement.

## Python

- Cache: `env.flush_all()`, `records.flush_model()`,
  `records.flush_recordset()`, `env.invalidate_all()`,
  `records.invalidate_model()`, `records.invalidate_recordset()`. In the
  shell {{commit}} and {{rollback}} already do this.
- Access rights and record rules are one model, `ir.access`.
  `env['ir.model.access']` and `env['ir.rule']` raise `KeyError`, and their
  tables are dropped. A row with a `group_id` grants, a row without one
  restricts; `operation` is a subset of `crud`, `domain` limits the records.
- `ir.config_parameter.get_param` and `set_param` are gone. Read with
  `get_str`, `get_bool`, `get_int`, `get_float`; write with `set_str`,
  `set_bool`, `set_int`, `set_float`.
- `read_group(domain, groupby, aggregates)` now has the `_read_group`
  signature and returns tuples; aggregates are `'amount:sum'` or
  `'__count'`. The dict-returning form is gone. The web client calls
  `formatted_read_group`.
- Constraints and indexes are `models.Constraint`, `models.Index`,
  `models.UniqueIndex` as in 19; `_sql_constraints` is not applied.
- Access checks are `check_access`, `has_access`, `_filtered_access`.
  `check_access_rights` and `check_access_rule` are gone.
- `env.registry.clear_cache()` is `env.transaction.invalidate_ormcache('default')`.
- `ir.attachment.datas` is ignored, with a warning, and the file comes out
  empty. Write `raw`: a `str` is taken as base64, `bytes` are stored as-is.
- `res.partner.is_company` is computed from `has_vat` and
  `commercial_partner_id`; writing `True` does not stick.
  `company_type` and `company_name` are gone.
- `_rec_names_search` is a tuple: `('name',)`, with the comma.
- Group membership is `group_ids` / `user_ids` and a group's
  `privilege_id`, as in 19. `Domain` from `odoo.fields` as in 19.
- `SQL` (`from odoo.tools import SQL`) is the way to compose a raw query.
  Never build the query with `%` or an f-string on a plain string.
- Models and modules that are gone: `web_editor` (now `html_editor`),
  `hr.contract` (`hr.version`), `procurement.group` (`stock.reference`),
  `stock.quant.package` (`stock.package`).

## XML

- Access is `security/ir.access.csv`, listed under that name in the
  manifest:

  ```text
  id,name,model_id,group_id/id,operation,domain
  access_thing_user,thing user,my.thing,base.group_user,crud,
  thing_own_rule,own things,my.thing,base.group_user,r,"[('user_id', '=', user.id)]"
  ```

  `model_id` is the dotted model name, not an XML ID.
- The list view root is `<list>`, type `list`, `view_mode` `list,form`,
  xpath `//list`. Modifiers are Python expressions on the attribute. A
  kanban card is `<t t-name="card">`.
- `t-call` is valid only on a `<t>` element. Values for the called template
  are attributes on that tag, not `t-set` children; the body becomes slot
  `0` (`t-out="0"`).
- In data XML a file field is `type="bytes"`. `type="base64"` still loads
  and warns `Since 20.0, use type=bytes instead of type=base64`.
- Client templates under `static/` are Owl 3: `t-out`, not `t-esc`, and
  `proxy()` instead of `useState()`. Server QWeb reports keep their `t-esc`;
  a global replace breaks them.
- A JSON controller is `@http.route(..., type='jsonrpc')`.

## Icons

- Font Awesome is gone. A `fa fa-*` class draws nothing and raises nothing:
  the icon is an empty space. Never carry one over from 19 unchanged.
- An icon is Material Symbols: `<i class="oi" data-icon="check_circle"
  title="..."/>`. Size with `oi-fw`, `oi-lg`, `oi-2x`. `oi-filled` gives
  the filled form; leave it off for the outlined one, which is what a
  `fa-*-o` was.
- On a button, `icon="check_circle"`, without the `fa-` prefix.
- Names are snake_case: `check_circle`, `error`, `warning`, `settings`,
  `power`, `business`, `tune`, `badge`, `info`, `lock`, `play_circle`.
- The font is a cut-down subset. A name outside it renders empty, again
  without an error — `apartment` is one. Use only names listed in
  `addons/web/tooling/icons/icons_wishlist.txt`, check every new one there
  with {{source}}, and look at it in the UI.
- In SCSS and JS, a `.fa` selector becomes `.oi`.
- Before a commit, `grep -rnE '\bfa fa-|icon="fa-' <module>/` must print
  nothing.
